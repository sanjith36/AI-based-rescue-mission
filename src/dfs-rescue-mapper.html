Search

The algorithm

DFS(start, target):
  stack   ← [start]
  visited ← { start }
  while stack is not empty:
    pixel ← top of stack
    if pixel has an unvisited road neighbour n:
        visited ← visited + { n }
        push n
        if n = target: return stack    # the path
    else:
        pop                            # backtrack
  return NO ROUTE                      # target is cut off

How the map becomes a graph

A black-hat filter picks out thin lines that differ from the ground around them, so water edges, parks and big shapes are ignored. The detected lines are thinned to one-pixel centerlines. Each centerline pixel is a node with up to eight neighbours, so the search follows the real curves of the streets.

The stack is the path the rescue unit is walking right now. When the search ends with an empty stack, every road reachable from the base has been checked and the target is not among them. Those cut-off roads need air rescue or debris clearing.

Switch to BFS to compare. DFS finds a route quickly but not the shortest one. Lengths count centerline pixel steps.
